# CHAIN27 Lab

רשת בלוקצ'יין ניסיונית שנכתבה מאפס, לניסויים ואיסוף נתונים. זו מעבדה ולא מוצר: הכול רץ כהדמיה במחשב אחד, בזמן מדומה.

**מה יש בה:**
- 27 צמתים מאמתים, ב-22 צמתי יסוד ו-5 צמתי מנצפ"ך, ברשת שבה כל צומת מחובר לכל צומת.
- קונצנזוס BFT בסגנון Tendermint (הצעה, קול מקדים, קול סופי), עם נעילות, דילוג סבבים, סנכרון בלוקים ושליחה חוזרת של קולות כשהרשת תקועה.
- השעיה של מציע שנכשל, המימוש הפשוט של "מדד האמינות" מה-Whitepaper 1.1.
- מטבע מובנה בשם ESH27-test: היצע קבוע של 270 מיליון, עמלה דינמית, 50% שריפה, 40% למציע, 10% לקרן הצדקה, ותגמול בלוק מהאוצר.
- הזרקת תקלות: צמתים שנופלים וחוזרים, צמתים איטיים, וצמתים זדוניים ששולחים הודעות סותרות ונקנסים.
- מדידה של Ed25519 אמיתי עם הספרייה `cryptography`. זמן האימות שנמדד נכנס להדמיה כעלות CPU.

## הרצה

```bash
cd chain27-lab
pip install -r requirements.txt
python run_experiments.py           # כל הניסויים, בערך דקה
python run_experiments.py --quick   # גרסה קצרה
python tests/test_chain27.py        # בדיקות
python exp_coin.py                  # ניסוי 01: כלכלת המטבע -> results/coin/
python exp_attack.py                # ניסוי 02: קנוניה של תוקפים -> results/attack/
```

התוצאות נכתבות ל-`results/`: הדוח ב-`REPORT.md`, גרפים ב-PNG, ונתונים גולמיים ב-CSV ו-`summary.json`. ה-seed קבוע, ולכן כל הרצה מחזירה את אותם מספרים.

## ניסוי משלך

```python
from chain27lab.world import Config, World

cfg = Config(
    duration=60,                 # שניות של זמן מדומה
    tps=500,                     # ביקוש עסקאות
    jail_blocks=100,             # השעיית מציע שנכשל (0 = סבב רגיל)
    behaviors={3: "equivocate", 7: "slow"},       # honest / crash / slow / equivocate
    schedule=[(20, "crash", [1, 2]), (40, "restore", [1])],
)
print(World(cfg).run())
```

## מבנה

| קובץ | תפקיד |
|---|---|
| `chain27lab/sim.py` | לולאת אירועים, מודל רשת (השהיה, רוחב פס, איבוד הודעות), מאגר עסקאות |
| `chain27lab/node.py` | צומת מאמת וכללי הקונצנזוס |
| `chain27lab/ledger.py` | המטבע: יתרות, עמלות, שריפה, אוצר, קנסות |
| `chain27lab/world.py` | הרכבת רשת, עומס עסקאות ומדדים |
| `chain27lab/economics.py` | הדמיה כלכלית מהירה בלי קונצנזוס |
| `chain27lab/crypto_bench.py` | מדידת Ed25519 ו-SHA-256 |
| `run_experiments.py` | כל הניסויים והדוח |

## מגבלות

ראה את סוף `results/REPORT.md`. בקצרה: אין רשת אמיתית, אין חתימה על כל הודעה, המאגר משותף, וקיים רק סוג אחד של תוקף. המספרים מראים מגמות ומגבלות של התכנון, ולא ביצועים של מוצר.
