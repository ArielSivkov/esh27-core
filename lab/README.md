# ESH27 Lab — מעבדת המתמטיקה והפיזיקה התיאורטית של S27

> **המשימה:** להפוך לחוקרים במתמטיקה ובפיזיקה תיאורטית בעזרת AI ובזכותו.
> בוחרים מטרה מבנק המטרות, תוקפים אותה עם נחיל סוכנים, **מאמתים פורמלית** (Lean 4) ומפרסמים את ההתקדמות בפומבי.

## עיקרון היסוד: אימות לפני הכרזה

מודל שפה הוא **מחולל לא-אמין**: הוא מציע רעיונות, בניות והוכחות. מה שקובע אם משהו נכון הוא **ליבת האמון**:
הוכחה ב-Lean 4, או חישוב שאפשר לשחזר עם תעודה (למשל הוכחת DRAT מפותר SAT, או בנייה שנבדקה בחשבון מדויק).

| רמה | משמעות | מה מותר להגיד |
|---|---|---|
| L0 | רעיון / השראה | "יש לנו כיוון" |
| L1 | עדות נומרית / חישובית | "בדקנו עד N" |
| L2 | הוכחה לא-פורמלית | "יש טיוטת הוכחה" |
| L3 | מאומת ב-Lean / תעודה חישובית | "הוכח (מאומת מכונה)" |
| L4 | עבר ביקורת עמיתים / פורסם | "פורסם" |

## מקור האמת

מעקב חי ב-Google Sheets (תצוגה מקוצרת של בנק המטרות):
https://docs.google.com/spreadsheets/d/1V9coJlUiul7Z8uRsovujRcw9KB6DWcYMtOQhWudvhNo/edit

קובצי ה-CSV ב-`data/` הם מקור האמת. האקסל, ה-Google Sheet והאתר הם **תצוגות** שנבנות מהם:

```bash
python scripts/build_workbook.py   # -> ESH27-Lab.xlsx
python site/build.py               # -> site/dist/index.html
python -m orchestrator.run --next  # מה המטרה הבאה?
```
