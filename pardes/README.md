# פרדס רימונים · ל"ב דרכים

אתר סטטי (ללא שלב build) לספר פרדס רמונים לרמ"ק: הטקסט המלא (32 שערים, 285 פרקים) ול"ב דרכי לימוד, חקר, מידול ותוצרים, דרך אחת לכל שער.

## הרצה מקומית
```
cd pardes && python3 -m http.server 8000
# http://localhost:8000
```

## מבנה
- `source/pardes_rimonim.txt` טקסט המקור (מקור דיגיטלי: hebrew.grimoar.cz)
- `tools/build_data.py` בונה את קובצי הנתונים מהמקור: `python3 pardes/tools/build_data.py`
- `data/gates/N.json` טקסט כל שער לפי פרקים ופסקאות
- `data/meta.json` כותרות, פתיחות, מונחים אופייניים, תוכן עניינים
- `data/stats.json` אזכורי ספירות ומקורות לכל שער, הפניות בין שערים, הופעה משותפת של ספירות
- `data/kinuyim.json` ערכי שער כ"ג (מילון הכינויים, חילוץ אוטומטי)
- `data/lexicons.json` גוונים, אותיות, נקודות, טעמים, שמות, היכלות, נשמה, עולמות
- `data/ways.json` תוכנית ל"ב הדרכים (שאלה, שיטה, תוצר, המשך מחקר)
- `index.html`, `assets/` האפליקציה

כל המספרים הם ספירות אוטומטיות (ביטויים רגולריים והופעה משותפת בפסקה). הם כלי עזר ללימוד, לא מסקנה מחקרית.
