# גרף הידע של ESH27

גרף אחד, סכמה אחת, שכבות. מקור האמת הוא שני קבצים: `data/nodes.json` ו-`data/edges.json`.
כל השאר (מדדים, אינדקס וקטורי, ייצוא) נגזר מהם וניתן לבנייה מחדש.

## שלושה כללים שלא נשברים

1. **כל קשת היא טענה עם מקור.** קשת היסטורית או טקסטואלית (`E1`–`E4`, `AUTHORED`) ברמת ביסוס `EXTRACTED` חייבת מראה מקום בספריא וציטוט של 3 מילים לפחות, שנבדק מכנית.
2. **עובדה אינה משל.** `E5`, `E6`, `CHANNEL`, `MAPS_TO` הם תמיד `STRUCTURAL_MAPPING`. קשת היסטורית לעולם אינה `STRUCTURAL_MAPPING`.
3. **מחלוקת היא אזרח ראשון.** שתי טענות סותרות נשמרות שתיהן: `claimed_by` אומר לשיטת מי, `disputes` מצביע על הקשת החולקת, `rank` מסמן מה מועדף. לא מוחקים דעה.

## צומת

| שדה | חובה | הסבר |
|---|---|---|
| `id` | כן | `<type>:<slug>` באנגלית קטנה, למשל `person:hillel`. קבוע לעד, לא משנים. |
| `type` | כן | `person` `work` `concept` `sefira` `school` `place` `event` |
| `label_he`, `label_en`, `aliases` | he חובה | שמות |
| `layer` | כן | `torah` כרגע. שכבות עתידיות: `sefirot`, `science`, `civic` |
| `cluster_id` | לא | אשכול G03 (`P01`–`P40`). שיוך בלבד, לא צומת |
| `era` | לא | תקופה |
| `external.wikidata`, `external.sefaria_topic` | לא | מזהים חיצוניים. מקשרים, לא מייבאים. `null` עד שאומת |
| `text_he` | כן | משפט תיאור. זה הטקסט שממנו נבנה האינדקס הווקטורי |

## קשת

| שדה | הסבר |
|---|---|
| `id` | `e:0001` רץ |
| `source`, `target` | מזהי צמתים. אסורה לולאה עצמית |
| `type` | `E1` מסירה · `E2` שושלת · `E3` מחלוקת · `E4` פירוש · `E5` ארכיטיפ · `E6` קרבה מחושבת · `AUTHORED` · `CHANNEL` · `MAPS_TO` |
| `basis` | `EXTRACTED` כתוב במקור · `INFERRED` מוסק ממקורות · `STRUCTURAL_MAPPING` משל מסומן |
| `claimed_by` | מזהה צומת של בעל השיטה, או `null` כשאין חולק |
| `rank` | `preferred` `normal` `deprecated` |
| `valid.from`, `valid.to` | תוקף בזמן (שנה), או `null` |
| `refs[]` | `sefaria_ref` + `quote` |
| `disputes[]` | מזהי קשתות חולקות |
| `added_by` | מי הוסיף |

## כלים

```
python3 graph/tools/kg.py validate   # כללי המבנה, בלי רשת
python3 graph/tools/kg.py verify     # כל ציטוט מול ה-API של ספריא
python3 graph/tools/kg.py metrics    # ספירות, בטי, PageRank, מרכזיות תיווך
```

קשת שלא עוברת `validate` ו-`verify` לא נכנסת.

## שכבה וקטורית

נגזרת, לא מקור. נבנית מ-`text_he` של הצמתים ומה-`quote` של הקשתות אל `graph/derived/` (לא ב-git),
עם קובץ מניפסט: שם המודל, ממד, וגיבוב של קובצי המקור. מחליפים מודל ובונים מחדש.

## ייצוא

`context.jsonld` ממפה את השדות ל-schema.org ולוויקינתונים, כך שהקבצים נקראים גם כ-JSON-LD.

## סולם 10 הרמות

1. סכמה וחוזה מזהים (הקובץ הזה)
2. זרע של 40–60 דמויות מאומתות
3. מדדים ואימות אוטומטי
4. שכבת הספירות מפרדס רימונים
5. קישור לוויקינתונים ולנושאי ספריא
6. הרחבה ל-150 דמויות ומעלה, ולחיבורים
7. שכבה וקטורית וחיפוש סמנטי
8. גישה לסוכנים דרך API ו-MCP
9. חילוץ אוטומטי עם ביקורת
10. שכבות נוספות ומוצר ציבורי

מצב: רמה 1 בנויה. הזרע הנוכחי (4 צמתים, 5 קשתות) הוא דוגמת פורמט מאומתת בלבד.
