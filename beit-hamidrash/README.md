# בית המדרש הגדול · ESH27

ספרייה תורנית מלאה ורשת לימוד חברתית מבית היוצר של ESH27. כל אחד יכול לכתוב פירוש על כל פסוק ומשנה, להעלות מאמרים ולתת הסכמה. כל פעולה נחתמת דיגיטלית, ואפשר להעביר אותה בין מחשבים ברשת סגורה או בדיסק און קי, בלי אינטרנט.

## המחלקות (מה בנוי כעת)

| מחלקה | קובץ | מה היא עושה |
|---|---|---|
| הספרייה הגדולה | `bhm/library.py`, `bhm/sefaria.py` | מחזיקה טקסטים לפי גרסה ויחידה (פסוק, משנה, סעיף), ומייבאת את כל מאגר ספריא דרך השער המשפטי |
| המחלקה המשפטית | `bhm/legal.py` | שער רישוי לכל גרסה. רק "בוודאות מותר" נכנס. כל דחייה נרשמת ביומן לבדיקה ידנית |
| בית המדרש | `bhm/ledger.py`, `web/` | פירושים, מאמרים, תגובות, הסכמות, פרופילים. הכול כאירועים חתומים |
| בתי הדין | `bhm/beitdin.py` | טיוטות לפסקי הלכה בלבד: מקורות חובה, הערות עיון, חתימת דיין מוסמך |
| יחידת חיתום נתונים וסייבר | `bhm/signing.py`, `bhm/bundle.py` | מפתחות Ed25519, חבילות עדכון חתומות לדיסק און קי, בדיקות נגד זיוף והחדרה |

## מצב הספרייה (ייבוא ראשון, 07.11.2026)

הייבוא עבר על כל 7,289 קובצי הגרסאות העבריות בייצוא הציבורי של ספריא:

- **5,213 גרסאות נחלת הכלל / CC0** נכנסו (שכבה A, "בוודאות מותר").
- **540 גרסאות CC-BY / CC-BY-SA** נכנסו עם חובת ייחוס (שכבה B). אפשר לכבות אותן בדגל `--no-b`.
- **1,587 גרסאות נדחו**: 945 ברישיון לא ידוע, 360 ברישיון לא-מסחרי, ו-282 שמסומנות "נחלת הכלל" אך הן יצירות מודרניות (משנת 1950 והלאה). את אלה צריך לבדוק ידנית.
- סך הכול כ-2.65 מיליון קטעי טקסט.

הספרים הראשונים:

- **ספר התורה:** "Tanach with Ta'amei Hamikra" (כתב יד לנינגרד, נחלת הכלל) הוא הטקסט הבסיסי. "מקרא על פי המסורה", המבוסס על כתר ארם צובה, נכלל ברישיון CC-BY-SA עם ייחוס.
- **ספר יצירה:** דפוס ורשה תרמ"ד, שתי הנוסחאות, עם פירושי הגר"א, הראב"ד, הרמב"ן, רס"ג ופרי יצחק. הכול נחלת הכלל. גרסת אריה קפלן נדחתה, כי הרישיון שלה לא ידוע.

מסד הנתונים (`var/library.db`, כ-3GB) לא נשמר ב-git. הוא מופץ בחבילות חתומות.

## הרצה

```bash
pip install fastapi uvicorn cryptography
cd beit-hamidrash
python -m bhm init                          # מפתח רשות העדכונים של המחשב
python -m bhm harvest json/Tanakh/Torah/    # או בלי קידומת: כל הספרייה
python -m bhm user add reuven "ראובן"
python -m bhm grant reuven talmid_chacham   # talmid_chacham / moderator / dayan
python -m bhm serve                         # http://127.0.0.1:8000
python -m pytest tests                      # 26 בדיקות
```

### דיסק און קי

```bash
python -m bhm bundle export /media/usb/update --title Genesis --title "Sefer Yetzirah"
# במחשב המקבל:
python -m bhm trust <PUBKEY> "רשות העדכונים המרכזית"
python -m bhm bundle verify /media/usb/update
python -m bhm bundle import /media/usb/update
```

המחשב המקבל דוחה את כל החבילה אם קורה אחד מאלה:
- החותם אינו מורשה במחשב הזה.
- חתימה או גיבוב (hash) של קובץ לא תואמים.
- יש בחבילה קובץ שלא מופיע ברשימה, קובץ הרצה, קישור סמלי (symlink), או נתיב שבורח מתיקיית החבילה.

כל גרסת טקסט עוברת שוב את השער המשפטי של המחשב המקבל. כל אירוע נבדק בחתימה שלו. דבר מהחבילה לא מורץ.

## עקרונות

- **אין פסק במערכת.** בית הדין מנהל טיוטות בלבד. טיוטה שלא נחתמה בידי דיין מוסמך מוצגת תמיד עם ההודעה: "טיוטה בלבד. אין זה פסק הלכה ואין לנהוג על פיו". טיוטה שנכתבה בסיוע מודל מסומנת בנפרד. חתימה של מי שאינו דיין לא נספרת. העמדה הזו תואמת את מה שהמחקר מצא: צוהר, ישיבה יוניברסיטי, ואיסורים מפורשים בחוגים חרדיים.
- **הפיקוח לא מוחק.** הסתרה היא אירוע חתום של מפקח. ההיסטוריה נשמרת וניתנת לאימות.
- **הרשאות מחושבות בזמן קריאה.** מינויים תקפים רק כשרשות מורשית חתמה עליהם. כך שני מחשבים שנפגשו רק בדיסק מתמזגים לאותו מצב, בלי תלות בסדר הייבוא.
- **שמירה בקוד רק במוצאי שבת.**

## פערים ידועים ושלבים הבאים (מתוך נחילי המחקר)

1. **מעטפת תוכן.** היום גוף הפירוש נמצא בתוך האירוע החתום, ולכן אי אפשר למחוק תוכן אסור בלי לשבור את החתימה. השלב הבא: האירוע יחתום על hash של התוכן, והתוכן יישמר בנפרד. כך אפשר להשמיד תוכן ולשמור על השרשרת (כמו בפרוטוקולים SSB ו-AT Protocol).
2. **מבנה מפתחות בסגנון TUF.** מפתח שורש לא מקוון, עם חתימת סף של 2 מתוך 3 בעלי מפתח בפיקוח רבני. מפתחות נפרדים לנתונים ולתוכנה. תוקף וגרסה לכל חבילה, כהגנה מפני גלגול לאחור (rollback).
3. **תחנת קליטה ייעודית לדיסקים.** חיבור לקריאה בלבד ובלי הרצה (noexec), חסימת כל סוגי ההתקנים חוץ מאחסון, ולא על מחשבי הלומדים.
4. **חבילות עדכון חלקיות.** חבילה עם "תנאי קדם" כמו `git bundle`, במקום לייצא את כל האירועים בכל פעם.
5. **מפתח לכל מכשיר.** כל מכשיר מקבל מפתח משלו שחתום במפתח הזהות של האדם, כדי שלא יתפצל יומן כשאותו מפתח משמש בשני מחשבים.
6. **המחלקה המשפטית.** לבדוק ידנית את 282 היצירות המודרניות שסומנו "נחלת הכלל", ולאשר אותן ב-`MANUAL_ALLOW` עם נימוק. לפנות בכתב לדיקטה ולמכון ממרא. לא לייבא מאוצר החכמה, מאגר בר-אילן, על התורה, תורת אמת או HebrewBooks בלי הסכם. לפי פסק דין קמרון (2000), גם מהדורה מודרנית של טקסט עתיק מוגנת. לקבל ייעוץ מעורך דין זכויות יוצרים ישראלי.
7. **נטפרי וספקי אינטרנט כשר.** לפני עלייה לציבור צריך בעלים מזוהה ואחראי, פיקוח רבני או של בית דין על תוכן הגולשים, אתר על דומיין יציב בלי רשתות הפצה (CDN) ומעקב של צד שלישי, ופנייה ישירה לנטפרי.
9. **בינה מלאכותית מקומית (הרישיונות נבדקו):**
   - הרצה: llama.cpp או Ollama (רישיון MIT).
   - מודל עיקרי: DictaLM-3.0-24B (רישיון Apache-2.0, קובץ של כ-14GB אחרי דחיסה), או 1.7B למחשב חלש.
   - חיפוש לפי משמעות: multilingual-e5-large או BGE-M3 (MIT).
   - ניתוח לשון חז"ל: BEREL_3.0 (Apache-2.0).
   - לא להשתמש ב-Aya (רישיון לא-מסחרי), ב-Gemma 3, ב-Llama 3.1 או ב-DictaLM-12B עד לבדיקת הרישיון.
   - כלי הרשת של דיקטה (נקדן, מאתר מובאות) לא זמינים לשימוש מקוון ללא אינטרנט בלי הסכם.
10. **בקרת איכות לטקסט התורה.**
    - בדיקה אוטומטית של המספרים המקובלים: 304,805 אותיות, 5,845 פסוקים, 290 פתוחות ו-379 סתומות.
    - טבלת חילופי נוסח, למשל בין תימן לאשכנז וספרד (בראשית ט:כט, דברים כג:ב).
    - שכבות נפרדות לאותיות, לניקוד ולטעמים, לכתיב וקרי, ולמבנה הפרשיות והשירות.
    - הערה: בכמה קובצי WLC כתוב "redistributed only with permission". לכן צריך לעגן את הרישיון של מהדורת UXLC, ושל "מקרא על פי המסורה" (CC-BY-SA 4.0, לפי גרסה נעולה), בתוך מסמך הרישוי שמצורף לכל חבילה.
11. **ציות של מפעיל הפלטפורמה (פער שאיש לא כיסה, ונמצא בבדיקת ההשלמה):**
    - חוק הגנת הפרטיות, תיקון 13 (בתוקף מאוגוסט 2025): ממונה על הגנת הפרטיות (DPO), רמת אבטחה ומיפוי מידע.
    - נגישות לפי ת"י 5568.
    - בישראל אין "נמל מבטחים" לתוכן גולשים: צריך נוהל הסרה מסודר.
    - רישיון לתורמי פירושים: הכותב שומר על זכויותיו ומעניק רישיון לרשת. הפירוש נשמר בנפרד מהטקסט, כדי שתנאי השיתוף הזהה של הטקסט לא יחולו עליו.
12. **שותפות אפשרית עם אוצריא.** ספרייה תורנית פתוחה (MIT), מקוונת ומסוננת, שאין בה שכבה חברתית. אפשר לבנות עליה במקום לבנות את הספרייה מאפס.
13. **המשבצות הריקות בשוק, לפי סקירת השוק:**
    - פירוש של גולשים בדרגות אמון על גבי הטקסט.
    - רשת חברתית תורנית שמסננים כשרים יכולים לאשר.
    - שאלות ותשובות שמעוגנות לטקסט.
    - סנכרון מקוון בלי אינטרנט עם חתימה דיגיטלית.
    - בינה מלאכותית שרצה מקומית.

    בית המדרש הגדול מכוון בדיוק לחמש המשבצות האלה.

8. **מבנה מסמך פסק.** תבנית בסגנון פסק דין: בס"ד, שם בית הדין ומספר תיק, "בפני כבוד הדיינים", העובדות, הנימוקים והמקורות, וההכרעה. אפשרות להרכב של שלושה דיינים (`DEFAULT_REQUIRED_SIGNATURES`).
